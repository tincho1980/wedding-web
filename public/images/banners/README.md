# Imágenes de Banners

Colocá las 6 imágenes de los banners en esta carpeta con los siguientes nombres:

- `banner-1.jpg` - Primera imagen (lado izquierdo, primera posición)
- `banner-2.jpg` - Segunda imagen (lado izquierdo, segunda posición)
- `banner-3.jpg` - Tercera imagen (lado izquierdo, tercera posición)
- `banner-4.jpg` - Cuarta imagen (lado derecho, primera posición)
- `banner-5.jpg` - Quinta imagen (lado derecho, segunda posición)
- `banner-6.jpg` - Sexta imagen (lado derecho, tercera posición)

## Formato recomendado
- Formato: JPG o PNG
- Tamaño recomendado: 600x400px o proporción similar (16:9)
- Peso: Optimizá las imágenes para web (máximo 500KB cada una)

## Nota
Las imágenes se mostrarán con un efecto vintage/cinematográfico (sepia y escala de grises suave) para mantener el estilo de la página.
